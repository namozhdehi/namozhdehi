## Featured GIS Projects

### 🌳 1. DC Park Accessibility & Priority Planner

**ArcGIS Pro · ModelBuilder · ArcPy · ArcGIS Online · Experience Builder · Spatial Analysis**

An end-to-end GIS analysis identifying underserved Washington, DC communities and prioritizing potential park investment areas.

- Analyzed **147 usable parks and 571 Census block groups** using an **800-meter straight-line accessibility buffer**.
- Identified **6 underserved block groups representing 4,237 residents** and ranked 4 populated priority areas.
- Automated and validated workflows using **ArcGIS ModelBuilder and ArcPy**, including proximity analysis, population density, and weighted scoring.
- Published a **mobile-friendly interactive Web GIS application** for exploring ranked priority locations.

[![GitHub Repository](https://img.shields.io/badge/GitHub_Repository-24292F?style=for-the-badge&logo=github&logoColor=white)](https://github.com/namozhdehi/DC_Park_Accessibility_Planner)
